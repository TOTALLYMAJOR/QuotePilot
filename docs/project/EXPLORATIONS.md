Explorations are bounded learning programs, not shipped-capability claims.

| Exploration | Current evidence | Next decision gate |
|---|---|---|
| Ambient compatibility retirement | Large source/test cohort and Vercel deployment; authenticated and human parity remain unverified. | Accept hosted role/mobile parity and an explicit rollback before deleting compatibility surfaces. |
| Stripe Connect runtime | Isolated source, tests, unbound manifests, and provider-disabled adapters. | Review and separately authorize an exact staging plan before any cloud or provider mutation. |
| Steward silent pilot | Policy/compiler, fixed corpus, and non-authoritative local evaluation foundation. | Approve provider transport, consent, private persistence, and human-comparison protocol before runtime binding. |
| Buyer acquisition and activation | Test-only source contracts and a gated hosted-acceptance plan. | Establish restricted test credentials and bounded provider/Turnstile acceptance before opening buyer access. |
| Commercial value proof | Product workflow and likely buyer are inferable from source; customers, usage, revenue, retention, and outcomes are UNVERIFIED. | Collect direct buyer and production evidence without deriving business claims from source activity. |

An exploration graduates only when its required evidence is recorded in the
canonical Feature Matrix, Project Status, and proof register as applicable.
